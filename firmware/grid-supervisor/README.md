# grid-supervisor

Прошивка LilyGo T-CAN485: независимый от Raspberry Pi контроль переключения инвертора
MUST PV1800 между сетью и батареей (пишется только регистр 20105).
Принцип: подключение к сети разрешено всегда, отключение — только при полной уверенности.

- `lib/gs_core` — переносимое ядро без Arduino-зависимостей;
- `test/native` — тесты ядра и реплей инцидента (`make test`);
- `docs/calibration.md` — калибровка порогов.

## OTA поверх BatteryEmulator
Схема разделов (`min_spiffs`, слот приложения ~1.9 МБ) и загрузчик по OTA не меняются.
Первый образ обязан содержать рабочий OTA; восстановление — USB-C. Откат при неудачной
загрузке не проверен.

## Сборка
`make test` — нативные тесты. `pio run -e lilygo_330` — ESP32 (на ПК пользователя).
